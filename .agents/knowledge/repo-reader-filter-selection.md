# 过滤列表与当前阅读文章解耦

作用域：
- `repo`

适用：
- `src/modules/reader/pages/ReaderPage.tsx`
- `src/modules/articles/hooks/useArticles.ts`
- 文章筛选、已读或收藏状态变更、当前文章选择

结论：
- 用户从另一篇文章切换并打开未读文章时自动标为已读；已读文章不重复写入。
- 用户把当前文章手动标为未读后，重复点击当前选中行不自动改回已读；离开后重新打开才算新的阅读动作。
- 当前阅读文章不能只从过滤后的列表查询结果推导。已读或收藏 mutation 会刷新列表；当状态变化使文章不再满足当前筛选时，列表可以移除它，但阅读区应保留该文章，直到用户切换文章、订阅源或筛选条件。
- 同一文章的已读写入必须按用户意图顺序执行，并在导航时参考尚未完成的最新意图；mutation 的结果和错误只能更新发起时仍然有效的选择代次。
- `all` 查询确认文章不存在时仍应清理失效选择，不能让保留快照掩盖真实缺失。

联动：
- 修改文章 mutation 的 Query 失效策略、选择清理逻辑或筛选行为时，同步验证自动已读、手动未读、快速切换的写入顺序和过滤结果移除后的阅读区连续性。
