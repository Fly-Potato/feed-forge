## 架构

```
Capability files (capabilities/*.json)
    |
    v
Permission identifiers (strings like "dialog:default" or objects with scopes)
    |
    v
Command allow/deny sets (auto-generated by plugins + manual registration)
    |
    v
IPC invocations from frontend -> checked against allow/deny -> executed or rejected
```

能力（capability）是一组命名的权限集合，分配给特定的窗口和平台。多个能力可以应用于同一个窗口——权限是累加式的。

## 能力文件结构

位置：`src-tauri/capabilities/<name>.json`

```jsonc
{
  "$schema": "../gen/schemas/desktop-schema.json",
  // Unique identifier for this capability
  "identifier": "main-capability",

  // Human-readable description
  "description": "Capability for the main window",

  // Which windows this applies to (labels or patterns like "*-window")
  "windows": ["main", "settings-*"],

  // Which platforms this is active on (optional, defaults to all)
  "platforms": ["windows", "linux", "macOS"],

  // Permission identifiers (strings or scoped objects)
  "permissions": [
    "core:default",
    "fs:default",
    "dialog:allow-open",
    {
      "identifier": "http:default",
      "allow": [{ "url": "https://api.example.com/*" }]
    }
  ]
}
```

### 启用能力

能力会从 `capabilities/` 目录中自动发现。你也可以显式指定它们：

```json
{
  "app": {
    "security": {
      "capabilities": ["main-capability", "admin-capability"]
    }
  }
}
```

## 权限标识符

### 命名约定

```
<plugin-name>:<permission>
```

示例：
- `"core:default"` -- 默认核心权限（路径、事件、窗口、应用、资源、菜单、托盘）
- `"dialog:default"` -- 默认对话框权限（打开、保存、消息、询问、确认）
- `"dialog:allow-open"` -- 仅允许打开文件对话框
- `"fs:allow-read-text-file"` -- 仅允许读取文本文件
- `"shell:allow-open"` -- 仅允许打开 URL/路径

### 默认权限

插件会暴露一个 `default` 权限集，包含安全且常用的操作。例如：
- `"dialog:default"` 包含 open、save、message、ask、confirm
- `"fs:default"` 包含 read、write、mkdir、remove、rename、exists、copy

### 逐命令权限

如需细粒度控制，可使用单独的 allow/deny 权限：
- `"fs:allow-read-file"` 和 `"fs:deny-read-file"`
- `"shell:allow-execute"` 和 `"shell:deny-execute"`

### deny 优先级更高

当 allow 和 deny 同时作用于同一命令时，deny 胜出。

## 作用域配置

带作用域的权限将命令限制到特定的资源。不使用字符串形式的权限，而是使用对象形式：

### 文件系统作用域

```jsonc
{
  "identifier": "fs:scope",
  "allow": [
    { "path": "$APPDATA/**" },     // User's roaming app data
    { "path": "$HOME/.config/**" },  // Config directory
    { "path": "$DESKTOP/*" }        // Desktop files only
  ]
}
```

路径变量：`$HOME`、`$TEMP`、`$APPDATA`、`$APPDATA$`、`$DESKTOP`、`$DOCUMENT`、`$DOWNLOAD`、`$PICTURE`、`$VIDEO`、`$AUDIO`、`$PUBLIC`、`$RESOURCE`、`$CACHE`、`$CONFIG`、`$LOCALDATA`

### HTTP 作用域

```jsonc
{
  "identifier": "http:default",
  "allow": [
    { "url": "https://api.github.com/*" },
    { "url": "https://*.example.com/**" },
    { "url": "http://127.0.0.1:*/*" }   // Any localhost port
  ]
}
```

URL 模式支持 `*`（单段匹配）和 `**`（任意深度匹配）。

### Shell 作用域

```jsonc
// Allow opening any HTTPS URL
{ "identifier": "shell:allow-open", "allow": [{ "url": "https://*" }] }

// Allow executing a specific sidecar
{
  "identifier": "shell:allow-execute",
  "allow": [{ "name": "printscr", "cmd": "./addon/PrintScr.exe", "sidecar": false }]
}

// Allow spawning with specific command and args
{
  "identifier": "shell:allow-spawn",
  "allow": [{ "name": "git", "cmd": "git", "args": true }]
}
```

### Opener 作用域

```jsonc
{
  "identifier": "opener:allow-open-url",
  "allow": [{ "url": "https://*.example.com/*" }]
}
```

## 核心权限

Tauri 核心权限（以 `core:` 为前缀）：

```jsonc
[
  "core:default",       // All core defaults
  "core:path:default",  // App path access
  "core:event:default", // Event emit/listen
  "core:window:default",// Window operations
  "core:app:default",   // App info
  "core:image:default", // Image operations
  "core:resources:default", // Resource access
  "core:menu:default",  // Menu operations
  "core:tray:default",   // Tray icon operations
  "core:webview:default" // Webview operations
]
```

```jsonc
[
```

## 远程窗口

对于加载远程 URL 或提供多个来源的情况，创建一个远程专用的能力：

```jsonc
{
  "identifier": "remote-capability",
  "windows": ["main"],
  "remote": {
    "urls": ["https://*.tauri.app", "https://myapp.com"]
  },
  "platforms": ["windows", "linux", "macOS"],
  "permissions": [
    "core:default",
    "fs:default"
  ]
}
```

重要提示：远程窗口默认无法访问所有 IPC 命令——它们需要在远程能力中获得显式授权。

## 自定义命令

当你自己定义了 `#[tauri::command]` 函数时，需要将它们注册到权限系统中：

### 步骤 1：在 build.rs 中注册

```rust
fn main() {
    tauri_build::build();
    // If you need custom command permissions:
    // tauri_build::try_build(
    //     tauri_build::Attributes::new()
    //         .app_manifest(
    //             tauri_build::AppManifest::new()
    //                 .commands(&["my_command", "another_command"])
    //                 .build()
    //         )
    // ).unwrap();
}
```

### 步骤 2：定义权限（以便像插件一样复用）

创建 `src-tauri/permissions/my-commands.toml`：
```toml
"$schema" = "../gen/schemas/schema.json"

[[permission]]
identifier = "allow-my-command"
description = "Enables the my_command command."
commands.allow = ["my_command"]

[[permission]]
identifier = "deny-my-command"
description = "Denies the my_command command."
commands.deny = ["my_command"]
```

### 步骤 3：在能力中引用

```jsonc
{
  "permissions": [
    "my-commands:allow-my-command"
  ]
}
```

## 在 build.rs 中注册命令

对于不属于任何插件的自定义命令，在 build.rs 中注册它们：

```rust
fn main() {
    let mut commands = tauri_build::AppManifest::new();
    commands.command("my_command");
    commands.command("greet");
    commands.command("process_data");

    tauri_build::try_build(
        tauri_build::Attributes::new().app_manifest(commands.build())
    ).expect("failed to register commands for permission system");
}
```

如果不做这个注册，自定义命令仍然可以工作，但无法在能力中被选择性地 allow/deny。

## 安全头部 (CSP)

内容安全策略在 `tauri.conf.json` 中配置：

```json
{
  "app": {
    "security": {
      "csp": {
        "default-src": "'self'",
        "connect-src": "ipc: http://ipc.localhost https://api.example.com",
        "img-src": "'self' asset: http://asset.localhost blob: data:",
        "style-src": "'unsafe-inline' 'self' asset: http://asset.localhost",
        "script-src": "'self'",
        "font-src": "'self' asset: http://asset.localhost"
      }
    }
  }
}
```

### Tauri 专属的 CSP 来源

- `ipc:` -- 允许 IPC 消息（对 invoke/events 是必需的）
- `asset:` -- 允许从 asset 协议加载资源
- `http://ipc.localhost` -- IPC 连接端点
- `http://tauri.localhost` -- 应用来源（使用 `https://` 搭配 `useHttpsScheme: true`）

### 其他安全选项

```json
{
  "app": {
    "security": {
      "freezePrototype": false,  // Freeze Object.prototype (enabled by default)
      "dangerousDisableAssetCspModification": false  // DON'T set to true
    }
  }
}
```

## 故障排查

### 命令不工作 / "command not found" 错误

请按顺序检查以下各项：
1. 命令是否已在 lib.rs 的 `generate_handler![]` 中注册？
2. 能力文件是否包含了所需的权限？
3. 窗口标签是否匹配能力中的 `windows` 之一？
4. 命令是否在 deny 列表中？

### 权限未找到错误

- 检查插件是否已在 builder 中注册：`.plugin(tauri_plugin_xxx::init())`
- 检查权限标识符是否使用了正确的前缀（如 `dialog:` 而不是 `dialog-plugin:`）
- 运行 `pnpm tauri dev`——它会自动生成 schema 文件并验证权限

### 远程窗口无法调用命令

- 添加一个带有 `remote.urls` 字段且匹配远程来源的独立能力
- 远程能力必须列出窗口所需的相同权限

### 在运行时检查已应用的权限

生成的 `gen/schemas/capabilities.json` 展示了已解析的权限集：
```
src-tauri/gen/schemas/capabilities.json
```
